# Oakey LTM (Language Tracking Model) V4

Static app hosted with GitHub Pages. Open `index.html` through the Pages address, then Add to Home Screen on iPhone.
Your data is not in this repo: it is saved in your browser, and (optional) to a private repo through Settings, Device sync.

Updating: replace `index.html`; if icons or fonts change, also bump `CACHE` in `sw.js`.
